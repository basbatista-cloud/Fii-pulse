Integração B3 (brapi.dev)

O FII Pulse consulta cotações e dividendos reais da B3 usando a API pública da brapi.dev. Você pode usar sem token (modo gratuito público) ou colar seu token gratuito de brapi.dev para maior limite de requisições.
